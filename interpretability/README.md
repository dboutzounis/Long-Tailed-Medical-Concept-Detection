# Interpretability (Sections 4.5-4.8, 5.6-5.9)

Submit each SLURM job from the folder that contains it (create `logs/` first).

## µMoE heads (`mumoe/`, Sections 4.5, 5.6)

The linear head of EfficientNetV2-M is replaced by a Multilinear Mixture of Experts head (CP rank 256, or Tensor Ring with ranks 4 and 128) with 32, 64, 128 or 256 experts, trained with ASL through the `cnn/` pipeline. The experts are then examined on the validation split: routing (top-1 load, dead experts, effective number of experts, concept enrichment) and counterfactual ablation, where each expert is removed in turn and the relative AP drop per concept gives its polysemanticity.

```bash
bash slurm/train_all.sh            # train the 8 heads (configs/*.yaml, generated by cnn/generate_configs.py)
bash slurm/train_all.sh eval       # val threshold and test F1 (Table 5.14)
sbatch slurm/run_all_ablations.sbatch          # routing + ablation of all runs (Tables 5.14-5.15)
python plot_mumoe_concepts.py --ablation-dir $WORK/Long-Tailed-Medical-Concept-Detection/results/mumoe_ablation \
    --taxonomy ../../data/taxonomy/concept_classifications.json --model tr_n32 --out-dir figures   # Figures 5.2-5.3, Table 5.16
```

`slurm/runs.tsv` lists the runs with the decision thresholds selected on validation by the eval jobs.

## Layer-wise probing (`layer_probing/`, Sections 4.6, 5.7)

Caches the CLS token of each of the 12 transformer blocks of BiomedCLIP and trains one linear probe per (layer, taxonomy category), 72 in total (Figure 5.4).

```bash
sbatch probe_hierarchy.sbatch      # extract_layers.py -> probe_hierarchy.py -> plot_probe_performance.py
```

## Dimensionality ablation (`dim_ablation/`, Sections 4.7, 5.8)

Projects the last-layer CLS tokens into BiomedCLIP's 512-d image-text space, fits PCA on the training split and trains an MLP probe on the first d components, for d from 512 down to 8 (Table 5.17, Figure 5.5). Uses the layer features of `layer_probing/`.

```bash
sbatch ablation.sbatch
```

## Grad-ECLIP (`gradeclip/`, Sections 4.8, 5.9)

Attribution maps for frozen BiomedCLIP, for the zero-shot cosine and the frozen linear head, compared with Grad-CAM, attention and random maps through deletion and insertion curves (Table 5.18, Figures 5.6-5.9). Needs the BiomedCLIP features, the frozen linear head (`vlm/frozen_heads/`) and the text embeddings (`vlm/zero_shot/extract_text_embs.py`).

```bash
python smoke_test.py               # CPU check with random weights, no data
sbatch run_gradeclip.sbatch        # maps, faithfulness and figures
python plot_gradeclip.py --out-dir $WORK/Long-Tailed-Medical-Concept-Detection/results/gradeclip/biomedclip \
    --select fn --n 8 --tag misses # near misses (Figure 5.8)
```
