# Long-Tailed-Medical-Concept-Detection
Code for the BSc thesis “A Representation Learning and Interpretability Approach for Long-Tailed Medical Concept Detection” (NKUA, 2026): CNNs, biomedical vision-language models (zero-shot, retrieval, LoRA) and interpretability (µMoE, probing, Grad-ECLIP) on ImageCLEFmedical 2026.
